# Contributing

Дякуємо за інтерес до проєкту! / Спасибо за интерес к проекту!

## Принципы

1. **Только открытые данные.** Не добавляйте источники, содержащие банковскую
   тайну, закрытые телеком-данные, учётные данные или утечки. Обезличивание
   физических лиц, предусмотренное источником, сохраняется и не обращается
   (`no_deanonymization`).
2. **Serverless.** Проект живёт только на GitHub Actions (+ Kaggle GPU +
   Hugging Face Hub). Не добавляйте код, требующий выделенного сервера.
3. **Воспроизводимость.** Любое преобразование данных должно быть
   детерминированным и самодостаточным: `scripts/` + CI должны пересобрать
   артефакт с нуля.

## Как предложить изменение

1. Форкните репозиторий и создайте ветку от `main`.
2. Код на Python должен проходить `python -m compileall scripts tests` и
   `python -m pytest tests/ -q` (зависимости: `pip install -r requirements-ci.txt`).
3. Для изменений в Kaggle-ноутбуках (`training/kaggle/`) убедитесь, что
   `scripts/patch_kaggle_notebooks.py` по-прежнему применяется
   (см. `tests/test_patch_kaggle_notebooks.py`).
4. Откройте Pull Request — CI («Ukraine data CI») проверит правила автоматически.

## Стиль коммитов

Conventional Commits: `feat:`, `fix:`, `chore:`, `docs:`, `test:` —
как в истории репозитория.
