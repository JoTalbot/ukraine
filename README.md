# Ukraine Legal Data

Проект для построения открытого AI-ready набора данных судебных решений Украины на основе официальных открытых данных ЄДРСР.

## Цель

Создать воспроизводимый pipeline:

`ЄДРСР → официальный архив → проверка целостности → нормализация → Parquet → Hugging Face Dataset → embeddings/индексация → поиск и RAG`

## Источник

Используются только официально опубликованные открытые данные и метаданные источника. Для каждого набора сохраняются provenance, дата загрузки и SHA-256.

## Репозитории и роли

- `JoTalbot/ukraine` — данные, ingestion pipeline, схемы, индексация и приложение.
- `JoTalbot/UASEP` — протокол автономной разработки и maintenance automation.

## Безопасность и качество

Не коммитить секреты, токены, приватные ключи и необезличенные пользовательские данные.

Каждый импорт должен иметь manifest с источником, периодом, размером, SHA-256 и статусом обработки.
