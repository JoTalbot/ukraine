# Ukraine Open Legal & Public Data

Проект для построения воспроизводимого AI-ready pipeline открытых данных Украины.

## Контур

`официальный источник → discovery → скачивание/архив → SHA-256 → нормализация → Parquet → Hugging Face → индексация/RAG`

Приоритетные направления:

- ЄДРСР и судебные решения за 2020–2026;
- список дел, назначенных к рассмотрению;
- состояние рассмотрения дел и банкротства;
- связь `заседание ↔ дело ↔ решение ↔ инстанция`, сохраняя предусмотренное источником обезличивание физических лиц;
- Prozorro и публичные закупки;
- публичные расходы и бюджеты;
- НАЗК и публичный реестр деклараций;
- ЄДР юридических лиц/ФОП и другие официальные бизнес-реестры, когда опубликованы как открытые данные;
- строительство и разрешительные данные;
- открытые геоданные и кадастровые наборы;
- Держстат;
- ЦИК и публичные результаты выборов;
- публичные данные НБУ;
- DREAM/восстановление;
- другие структурированные наборы Data.gov.ua;
- публичные страницы маркетплейсов, включая OLX, только в пределах их публичной информации и условий источника.

Каталог источников: `config/priority_open_data_sources.yml`.

## Автоматизация

Основной mirror workflow запускается вручную, каждые 30 минут и после успешного discovery. Для обнаруженных наборов используются `--max-dataset-files 0` и `--max-file-mb 0`, то есть искусственных ограничений по числу файлов и размеру файла в скрипте нет. Практические пределы определяются временем runner, сетью, доступным хранилищем и лимитами источника/Hugging Face.

Целевые Dataset repositories:

- `JoTalbot/ua-edrsr` — судебные данные;
- `JoTalbot/ua-open-data` — остальные открытые данные.

## Provenance и качество

Для каждого импорта сохраняются источник, период, дата загрузки, размер и SHA-256. Архивы ZIP/7Z/GZ и другие опубликованные форматы рассматриваются как ресурсы для скачивания, а не как причина искусственно ограничивать размер.

## Ограничения приватности

Проект использует только законно опубликованные открытые данные. Не собираются банковская тайна, закрытые телеком-данные, учётные данные, утечки или данные для снятия установленной анонимизации физических лиц.

## Репозитории и роли

- `JoTalbot/ukraine` — ingestion, схемы, данные, индексация и приложение.
- `JoTalbot/UASEP` — автономная разработка и maintenance automation.
