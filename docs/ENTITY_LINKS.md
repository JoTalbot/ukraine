# Entity linkage: связи между записями разных баз

`scripts/entity_links.py` строит граф сущностей поверх замкнутых датасетов и отвечает на запросы
«найди сущность и всё, что с ней связано».

## Модель

**Сущности (`entities`)**
- `edrpou` — 8-значный ЄДРПОУ юридической osoby (спина: ЄДР, `UO.zip`)
- `ipn` — 10-значный ІПН / номер ПДВ физлица-предпринимателя
- `name` — нормализованное (UPPERCASE) ФИО или название организации

**Упоминания (`mentions`)** — в каких базах встречается сущность:
`edr`, `vat_payers`, `edrsr`, `notaries`, `court_experts`, `arbitration_managers`,
`audit_subjects`, `auditors`, …

**Рёбра (`edges`)** — почему две сущности связаны:

| kind | откуда | смысл |
|---|---|---|
| `founder` | ЄДР `<FOUNDER>` | лицо — учредитель компании |
| `signer` | ЄДР `<SIGNER>` | лицо подписывает документы компании |
| `judges_in` | ЄДРСР metadata | судья рассматривает дела в суду |
| `co_litigant` | ЄДРСР text (если есть текст) | две компании в одном решении |
| `works_at` | реестры нотариусов/экспертов | лицо работает в организации |
| `linked` | аудиторский реестр | лицо связано с фирмой по ЄДРПОУ |

Вес ребра = количество подтверждающих записей.

## Сборка

```bash
python scripts/entity_links.py build \
  --db links.db \
  --edr UO.zip \                     # спина: 2 млн компаний + учредители/подписанты
  --vat pdv_actual.csv \             # 281k плательщиков ПДВ (ІПН/ЄДРПОУ)
  --xml-register notaries=17.zip \   # любые RECORD-XML реестры
  --xml-register court_experts=19.zip \
  --json-register audit_subjects=subjects.json \
  --edrsr-parquet '2026/part-*.parquet'  # судья~суд по всем решениям
```

Идемпотентность: повторный прогон добавляет weight, не дублирует сущности.

## Поиск

```bash
# по ИНН/ЄДРПОУ/ПДВ-номеру (12-значный ПДВ автоматически урезается до префикса)
python scripts/entity_links.py search --db links.db --id 351976413199
python scripts/entity_links.py search --db links.db --id 14359609

# по ФИО / названию
python scripts/entity_links.py search --db links.db --name "Ковальчук О. В." --depth 2
```

Вывод: карточка сущности → в каких базах упоминается → связанные сущности с весами,
обходом в глубину (`--depth`), отсортировано по силе связи.

## Приватность

Используются только идентификаторы и имена, уже опубликованные в открытых реестрах.
Обезличивание источника не обращается (`no_deanonymization`); граф не добавляет
персональных данных, которых нет в источниках.

## Демо-результаты (сборка 30.08.2026)

- entities ≈ 4.45 млн, mentions ≈ 2.3 млн, edges ≈ 4.9 млн
- пример: ЄДРПОУ → название, статус, учредители и подписанты (ЄДР), статус плательщика ПДВ,
  аудиторский статус фирмы
- пример: судья → суд(ы) с числом рассмотренных дел за 2026 год
